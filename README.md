# 🎬 Video Downloads

Aplicação desenvolvida em **JavaScript** para realizar downloads de vídeos através de URLs fornecidas pelo usuário.

O projeto tem como objetivo facilitar o download de conteúdos de vídeo utilizando uma interface simples e processamento assíncrono no backend.

---

## 🚀 Tecnologias utilizadas

- **JavaScript**
- **Node.js**
- **Express**
- **HTML5**
- **CSS3**
- **APIs de download de vídeo**

---

## 📌 Funcionalidades

✅ Download de vídeos através de URL  
✅ Processamento de arquivos de mídia  
✅ Interface web simples e intuitiva  
✅ Organização modular do código  
✅ Tratamento de erros durante downloads 

---

## ⚙️ Instalação

Clone o projeto:

```bash
git clone https://github.com/jotapeh1002/video-downloads.git
```

Entre na pasta:

```bash
cd video-downloads
```

Instale as dependências:

```bash
npm install
```

---

## 🔐 Configuração

Crie um arquivo `.env`:

```env
PORT=3000
```

---

## ▶️ Executando o projeto

Modo desenvolvimento:

```bash
npm run dev
```

Ou:

```bash
npm start
```

A aplicação estará disponível em:

```
http://localhost:3000
```

## 🔄 Processo de download

1. Usuário informa a URL do vídeo.
2. Backend recebe a solicitação.
3. A aplicação valida os dados.
4. O serviço responsável inicia o processamento.
5. O arquivo é gerado e disponibilizado.
